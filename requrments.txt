# 7. LLM

We need an LLM for the **cataloging assistant**.

The LLM receives:

```text
Product photo
+
Speech transcript
+
Artisan information
```

and produces structured information:

```json
{
  "name": "...",
  "category": "...",
  "material": "...",
  "description": "...",
  "keywords": [],
  "dimensions": "...",
  "craft_type": "..."
}
```

### Important

We don't need to build/train our own LLM.

Use an existing API/model.

The backend becomes:

```text
Flutter
   ↓
FastAPI
   ↓
AI Orchestrator
   ↓
LLM
```

This also means we can change the underlying model later without modifying the Android app.
