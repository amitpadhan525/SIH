For the **SIH demo**, everything can run locally or use free-tier services.

### But what about AI?

We have two approaches.

**Option A — Local/open-source**

```text
Flutter
   ↓
FastAPI
   ↓
Local AI models
   ├── Speech
   ├── Image
   └── NLP
```

Cost: **₹0 API cost**

But your laptop has limited resources, so we need to choose lightweight models carefully.

**Option B — Cloud APIs**

```text
Flutter
   ↓
FastAPI
   ↓
Cloud AI API
```

Much easier and often better quality, but usage can cost money.

---

### What I'd recommend for our SIH project

**Hybrid approach.**

Use open-source/local components wherever practical:

```text
Image processing       → Local
Pricing ML             → Local
Database               → Local
Backend                → Local
Frontend               → Local

LLM                    → API or local model
Speech-to-text         → API or local model
Translation            → API or open-source
```

Then we don't become dependent on a huge monthly bill.

### Server?

For development:

**No server.**

For the final SIH demo:

**Your laptop can even act as the server** if everyone is on the same network.

For a real deployed product later:

```text
Cloud VPS
      +
PostgreSQL
      +
Object Storage
      +
AI services
```

Then we'd pay perhaps a small monthly amount depending on traffic.

### One thing I would NOT do

Don't start paying for:

* AWS EC2
* expensive GPU servers
* OpenAI/other APIs
* SMS services
* managed databases

**before we know exactly what the prototype needs.**

First build the entire pipeline locally with free/open-source components. Then identify which AI components genuinely need a paid API.
